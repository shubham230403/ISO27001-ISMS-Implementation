\# ISO 27001:2022 Annex A Control Summary



\## Overview



ISO/IEC 27001:2022 Annex A contains 93 information-security controls organized into four themes.



| Theme | Controls |

|---|---:|

| A.5 Organizational | 37 |

| A.6 People | 8 |

| A.7 Physical | 14 |

| A.8 Technological | 34 |

| \*\*Total\*\* | \*\*93\*\* |



\## Project Approach



Each control is evaluated against:



\- Applicability

\- Implementation status

\- Control owner

\- Related information-security risks

\- Supporting evidence



\## Status Definitions



\### Implemented



The control is considered implemented in the simulated ISMS and supporting documentation exists.



\### Partial



The control framework exists but additional operational evidence, testing or maturity is required.



\### Not Implemented



The control has not yet been implemented.



\## Important



This repository represents a simulated portfolio implementation for learning and demonstration purposes. It is not evidence of ISO 27001 certification.
